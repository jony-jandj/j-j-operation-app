SELECTION PRINT UPDATE

1. Unzip this package.
2. Upload selection-print.js to the root of jony-jandj/j-j-operation-app on GitHub and commit.
3. Wait for the deployment to finish, then refresh the app (Mac Chrome: Command + Shift + R).
4. Open Selections > Print / PDF. Choose Selected + pending groups or Review all options to include favorites. Selected items only continues to show actual selections only.

Only selection-print.js goes to GitHub. No SQL or database update is needed. This can be installed alongside the prior homeowner-upload and gray Work Board/phone update; it does not replace those files.

Purple = Favorite. Gold = Pending / Recommended. Green = Selected / Ordered / Received.
Favorite allowance comparisons use each option’s price, quantity, and applied tax. Favorites do not add to selected totals. Multiple favorites are compared individually, not added together. Missing prices or allowances are clearly marked.
Fresh shared favorites load before printing. If that read fails, use Retry favorites. Product-title links remain clickable in PDF.

Checked with sample data and a generated PDF. No real job records were edited. Not deployed by this package preparation.
