Run WORK_PAY_SETUP.sql in the existing Supabase project first. Then replace work-pay.js and service-worker.js in GitHub and refresh all open app windows after deployment.

Approved P.O.s display locked amounts and assignments. Undo Approval returns the P.O. to Draft, removes its active summary earnings/payment allocations and retains the previous records in audit history. Other P.O. allocations in combined payments remain intact. This does not reverse actual bank payments.
