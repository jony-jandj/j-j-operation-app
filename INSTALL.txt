J&J Operations — Simplified split layout

This replaces the September 21 split release interface. No additional SQL or data migration is needed if you already installed that release's database update.

Extract this ZIP and upload all its files and folders into your existing GitHub repository, replacing matching files and preserving the folder structure. Do not upload only index.html, and do not upload the ZIP itself as the website.

After GitHub deployment finishes, close and reopen the app. Connect Work & Pay if prompted. Open a draft P.O.: Split line is now inside the P.O. Split section. After splitting, click the top heading to collapse/expand, or Edit on either line. Save keeps it Draft; Save & approve validates and approves the edited line together.

No production records were changed by preparation or testing of this package.
