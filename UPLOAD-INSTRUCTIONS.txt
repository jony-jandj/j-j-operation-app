What changed:
- Shared updates rebuild the visible section. Hidden sections refresh when opened, reducing unnecessary work in Dashboard, Estimates, Selections, Preconstruction, and project screens.
- Background app-state updates defer while you are typing or have an editor open, then catch up through polling.
- Startup sign-in, profile lookup, and live-data loading have bounded waits instead of hanging indefinitely on a stalled connection.
- Unchanged homeowner selection sync does not write to cloud, create redundant recovery snapshots, or redraw screens. Changed data still receives a recovery snapshot and the safe union merge.
- Homeowner sync can recover from a timeout rather than staying busy forever.
- Work Board keeps its cards and expanded Done list stable during unchanged refreshes. A successful move closes without waiting on a second network refresh.
- Concurrent ledger refreshes share one request. Bill listings index payees and payments instead of repeatedly scanning all records for every row.
- Previously installed app pages/assets can load from the app cache when a connection stalls. Old app-owned caches are cleaned up; unrelated caches are preserved.
- Updated script versions keep the changed modules loading together.

Validation:
- Full app browser checks: Dashboard / Work Board, Preconstruction, Selections, Estimates, P.O.s, Files, and Job Costing; job switching; phone/tablet/desktop viewport checks; no uncaught browser errors on those paths.
- Rapid crew entry, latest-edit approval, failed approval/retry, and partial-completion accounting regression checks passed.
- Simulated cloud timeouts release locks, preserve local changes, and allow retry. Initial-load timeouts do not replace local records.
- Selection sync checks cover unchanged data, added products/groups, local edits made during sync, and timeout recovery.
- App-cache tests cover slow network, offline fallback, healthy network updates, first load, and obsolete-cache cleanup.
